# lab-6

## Виконані вправи
1. **FILE READ** (`file_read.js`) - Обробка `GET`-запиту. Сервер читає вміст локального файлу `data.json` через `fs.readFileSync` та повертає його клієнту. Включає обробку помилок відсутності файлу (`500`) та зламаного JSON (`400`).
2. **FILE WRITE** (`file_write.js`) - Обробка `POST`-запиту. Отримання JSON-даних з тіла запиту та їх збереження у файл `data.json` за допомогою `fs.writeFileSync`.
3. **FILE UPDATE** (`file_update.js`) - Обробка `PUT`-запиту з динамічним параметром у маршруті (`/data/:id`). Знаходження об'єкта в масиві за `id`, його оновлення та перезапис файлу.
4. **FILE DELETE** (`file_delete.js`) - Обробка `DELETE`-запиту за `id`. Фільтрація масиву з файлу `data.json` для видалення конкретного елемента та збереження оновленої структури.

## Як запускати рішення

Всі скрипти працюють на базі вбудованих модулів `http` та `fs`. Для запуску треба відкрити термінал у папці з проектом та виконати:

node <назва_файлу> <порт>
